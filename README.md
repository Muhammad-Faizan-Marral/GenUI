# GenUI - AI-Powered UI Generator

**GenUI** is a modern web application that transforms natural language prompts into beautiful, UI components using AI. Built with **Next.js** and **Tailwind CSS**, it allows users to generate, view, and share their UI ideas instantly.

## 🚀 Features
- **Prompt-to-UI:** Enter a description and get a production-ready UI layout.
- **Instant Deployment:** Automatically saves generated code to a database.
- **Shareable Links:** Every generated project gets a URL for easy sharing.
- **Modern Tech Stack:** Fast, responsive, and styled with Tailwind CSS.

## 🛠️ Tech Stack
- **Framework:** [Next.js](https://nextjs.org)
- **Styling:** [Tailwind CSS](https://tailwindcss.com)
- **Database:** [Supabase]
- **AI Integration:** ...

## 🏗️ How It Works
1. **Login/Signup:** Secure user authentication.
2. **Describe:** User enters a prompt (e.g., "A modern landing page for a coffee shop").
3. **Generate:** Backend calls the AI API to generate Tailwind-based code.
4. **View & Share:** The code is stored, and a link is generated for the live preview.
